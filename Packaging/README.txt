EON-Vari mu DSP for macOS
============================

Supported system: Apple Silicon Macs (arm64)

AUTOMATIC INSTALL
-----------------
1. Double-click "Install EON-Vari mu DSP.command".
2. No administrator password is required.
3. When installation completes, restart or rescan your DAW.

The installer replaces these two bundles without asking:
  ~/Library/Audio/Plug-Ins/Components/EON-Vari mu DSP.component
  ~/Library/Audio/Plug-Ins/VST3/EON-Vari mu DSP.vst3

It does not remove or modify any differently named plug-ins.

If macOS prevents the script from opening, Control-click the installer,
choose Open, then choose Open again in the confirmation dialog.

MANUAL INSTALL
--------------
1. Quit every DAW.
2. Copy "AU/EON-Vari mu DSP.component" to:
   ~/Library/Audio/Plug-Ins/Components/
3. Copy "VST3/EON-Vari mu DSP.vst3" to:
   ~/Library/Audio/Plug-Ins/VST3/
4. Choose Replace if Finder asks about an existing EON-Vari mu DSP file.
5. Restart or rescan your DAW.

The Library folder inside your home folder may be hidden in Finder. Use
Finder > Go > Go to Folder... and paste the destination path above.
