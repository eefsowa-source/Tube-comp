질감을 다시 만들고 그리드를 조였다. 컨트롤 배치(위치)는 유지하고 렌더링

교체하는 것이 이번 단계의 내용이다.

## 3. 노브 질감

МОЛОТ 노브의 특징은 원통이 아니라 테이퍼드 콘이다. 위쪽 면이 좁고 밑면이
넓으며, 광택 있는 흑색 바켈라이트가 조바른 스펙큘러 하이라이트를 만든다.
`Source/UI/TubeCompLookAndFeel.cpp`의 `drawTurnedKnob()`가 이를 층으로 구성한다.

- 접촉 그림자(짧고 진함) + 넓고 옅은 페넘브라. 부품이 패널 위에 얹힌 느낌.
- 콘 스커트: 상단-좌측에 밝은 호, 하단에 어두운 호. 옆면이 실제로 기울었다는 신호.
- 좁은 상면: 도메인 링 + 얇은 밝은 모서리. 상면이 떠 보임.
- 광택 흑색 바켈라이트 상면 + 동심원 선반 자국.
- 하드 스펙큘러 스트릭(선택한 광원 방향) + 옅은 블룸.
- 테이퍼드 인디케이터와 작은 라운드 허브 캡.
- 실루엣선. 뒤에 인쇄된 눈금과 분리.

광원은 전 패널에서 하나(상단-좌측)다. 노브 림, 바디 돔, 허브 캡, 미터
베젤이 모두 같은 각도에서 밝아지므로 부품들이 각각 독립적으로 음영된
위젯이 아니라 하나의 조명을 받은 오브젝트로 읽힌다.

## 4. 그리드 간격

- 유틸리티 행 노브 gap 6 -> 2 px
- 채널 스트립 gap 8 -> 4 px
- 행 간격 rowGap 10 -> 6 px
- 노브 상한 78 -> 92 px, 링 다이얼 상한 122 -> 134 px
- 레이블 영역 34 -> 26 px, 노브-레이블 간격 6 -> 4 px

노브를 키우고 간격을 줄인 게 핵심이다. 레퍼런스는 노브 직경이 크고 셀이
촘촘해서 패널이 조밀한 기계식으로 보인다. 가독성은 눈금이 노브 바깥에
인쇄된다는 구조가 부담하므로 노브 크기로는 해결하지 않는다.

980x800 최소 크기에서 클리핑 없음(`editor-980x800.png`).

## 5. 남은 게이트

- 호스트 UI 상호작용(드래그/호버/리사이즈)은 오프스크린 스냅샷으로 증명되지 않는다.

- S3 트랜스포머의 레벨 매칭 블라인드 청취가 여전히 대기 중이다.

## 6. 리뷰에서 바로잡은 것

전체 파일 재빌드로 `-Wall` 경고를 다시 수집하고 세 가지를 고쳤다.

**죽은 매개변수.** `drawTurnedKnob()`의 `tallBody`는 받기만 하고
`ignoreUnused()`로 버려지고 있었다. 실제로 쓰게 만들었다. 레퍼런스의 가장 큰
다이얼은 작은 트림 노브보다 콘 벽이 눈에 띄게 높고, 이 높이 차이가 위계를
읽히게 하는 요소였다. 노브 전체를 확대하지 않고 어두운 내부 링을 바깥으로
키우는 방식으로 추가했다.

**미터 베젤 그림자 방향.** 다층 그림자를 두 축으로 같은 양만큼
확장하면서 이동시키고 있었는데, 그러면 모든 층이 베젤 중심에 정렬돼 대칭
번짐이 되고 미터가 파인 것처럼 보였다. 오른쪽과 아래쪽으로만 이동하도록
고쳐 파낸 부품처럼 읽히게 했다.

**하단 리세스 대비.** 검은 리프 알파 0.72로 올리고 좌측 벽 캐치라이트를
0.13에서 0.20으로 올렸다. 어두운 패널에서는 스텝이 거의 보이지 않아 리세스가
죽은 띠처럼 보였다.

경고는 전부 0이다 (`-Wfloat-conversion` 2건은 눈금 숫자 위치 계산의
float→int 암시 변환이었고 `roundToInt`로 명시했다, 미사용
`shadowAngleRadians` 상수 1건은 삭제, `drawSeam` 람다의 변수 섀도잉 1건은
이름 변경).
